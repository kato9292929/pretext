PROTOCOL

x402とは

HTTP 402 "Payment Required" ステータスコードは、インターネットの黎明期から存在していましたが、長らく未使用のままでした。x402はそのポテンシャルを解放します。

Coinbaseが主導するこのオープンスタンダードは、ウェブリクエストに支払いを組み込む新しい方法を定義します。サーバーが402を返したとき、クライアントは自動的に支払いを完了し、リクエストを再試行できます。

仕様を読む →
HTTP Flow 
→ GET /api/data HTTP/1.1
  Host: api.example.com

← HTTP/1.1 402 Payment Required
  X-Payment-Required: version=1
  X-Payment-Amount: 0.001
  X-Payment-Token: USDC

→ GET /api/data HTTP/1.1
  X-Payment: <signed_payload>

← HTTP/1.1 200 OK
  Content-Type: application/json

HOW IT WORKS

仕組み

01

リクエスト

クライアント（人間またはAIエージェント）がHTTPリクエストを送信します。

→
02

402レスポンス

サーバーが支払い条件（金額・通貨・アドレス）を含む402を返します。

→
03

支払い実行

ブロックチェーン上でオンチェーン決済が自動的に完了します。

→
04

アクセス付与

サーバーが支払いを確認し、200 OKでリソースを返します。

すべてのやり取りはHTTPの標準的な仕組みの上に構築されています。
既存のインフラを変更することなく、支払い機能を追加できます。

USE CASES

ユースケース

⚡

AIエージェント間決済

自律型AIエージェントが人間の介在なしにリアルタイムで決済。API呼び出しごとに自動的に課金・支払いが完結します。

✦

マイクロペイメント

0.001円単位の超小額決済が可能。記事1本、楽曲1曲、データ1件ごとの柔軟な課金モデルを実現します。

◎

コンテンツ収益化

サブスクリプション不要。読んだ記事、視聴したコンテンツに対してのみ支払う、公正な収益化モデル。

⬡

API マネタイズ

APIアクセスに対してリクエスト単位で課金。従量制の柔軟なビジネスモデルを簡単に構築できます。

↗

クロスボーダー決済

国境を越えた即時送金。従来の国際送金の複雑さと高コストを排除し、シームレスなグローバル取引を実現。

⊕

IoT・機械間取引

スマートデバイスが自律的に電力・データ・サービスを売買。M2M経済の新しい基盤を提供します。
